# 第八步：第一版趋势动量轮动回测

版本日期：2026年10月29日

## 策略规则

第一版策略只使用信号日收盘前已经存在的数据：

1. 候选ETF必须同时满足120日动量为正，以及收盘价高于200日移动平均线。
2. 使用“120日动量 ÷ 20日年化波动率”作为风险调整动量得分。
3. 每周最后一个交易日收盘后排名，最多选择3只ETF。
4. 当前目标中的ETF如果仍在前5名，可以使用持仓缓冲区保留。
5. 权重按波动率倒数分配，总目标仓位95%，单只ETF最多45%。
6. 新标的进入前3名时允许替换；标的退出前5名时强制退出。
7. 组合计划换手低于5%时不做调仓，超过50%时按比例缩小到上限。
8. 信号在下一交易日开盘执行，严格遵守T+1、整手、停牌、涨跌停和公司行动规则。

权重配置、回测日期和每笔订单都保存在结果表中，避免只保留最后的收益数字。

## 时间顺序

```text
每周最后一个交易日收盘
        ↓
用截至当日收盘的历史计算趋势、动量和波动率
        ↓
生成目标组合和权重
        ↓
下一交易日先处理公司行动、再提交卖出和买入
        ↓
检查T+1、整手、停牌、涨跌停和成交容量
        ↓
使用滑点、冲击、佣金后的成交价更新现金和持仓
        ↓
按未复权收盘价估值
```

回测最低首笔持仓信号出现在2012-12-17，所需预热历史来自2012年内的行情，组合和沪深300基准都从首笔实际目标组合起算。

## 成本压力结果

| 场景 | 期末权益 | 累计收益 | 年化收益 | 最大回撤 | Sharpe | 同期沪深300 | 超额收益 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 无成本 | 1,091,514.95 | 118.30% | 5.79% | -45.16% | 0.400 | 70.78% | 47.52% |
| 1倍成本 | 986,347.03 | 97.27% | 5.02% | -45.39% | 0.361 | 70.78% | 26.49% |
| 2倍成本 | 917,852.85 | 83.57% | 4.48% | -45.87% | 0.333 | 70.78% | 12.79% |
| 3倍成本 | 850,475.96 | 70.10% | 3.91% | -46.84% | 0.303 | 70.78% | -0.68% |

1倍成本下累计交易成本为89,088.45元，其中佣金35,634.51元。平均总仓位约62.1%，平均持仓约1.81只，年化单边换手约4.42倍。

## 结论

策略在1倍和2倍成本下取得高于沪深300的累计收益，但风险约束不合格：

- 最大回撤约45%，远高于20%的目标。
- 成本压力上升后超额收益快速缩小，3倍成本时几乎消失。
- 年化换手较高，收益对交易成本和执行假设敏感。
- 当前候选池使用当前确定的研究名单，仍存在样本选择偏差。

因此本版不能进入模拟盘，也不能因为历史累计收益高于基准就判定策略有效。下一步必须进行样本内/样本外分离、参数邻域、滚动向前验证和风险控制测试。

## 运行命令

首次更新沪深300基准：

```powershell
uv run quant-backtest update-benchmark
```

重新执行完整回测：

```powershell
uv run quant-backtest run
```

查看最近一次汇总：

```powershell
uv run quant-backtest summary
```

## 验收检查

- 所有日快照都满足现金加持仓市值等于权益。
- 所有订单的执行日期严格晚于信号日期。
- 总仓位从未超过100%。
- 单只ETF目标权重从未超过45%。
- 账户现金和持仓没有负数。
- 无未来价格泄漏的自动测试通过。
- 无成本、1倍、2倍和3倍成本使用完全相同的候选池、信号和目标规则。
