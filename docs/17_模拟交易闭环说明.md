# 第十七步：离线模拟交易闭环

版本日期：2026年10月29日

## 安全边界

- 只读取本地已验证数据。
- 只模拟成交和账户状态。
- 不连接券商账户。
- 不发送真实委托。
- `live_trading_enabled`和`broker_connected`固定为`false`。

## 状态与幂等

模拟盘状态保存在：

- `data/paper/state.json`
- `data/paper/snapshots.parquet`
- `data/paper/orders.parquet`
- `data/paper/targets.parquet`
- `data/paper/runs.parquet`

每笔模拟订单根据信号日、执行日、代码、方向和数量生成确定性哈希ID。重复运行同一日期会重建同一份结果，不会追加重复订单。

## 冻结保护

模拟盘启动时记录：

- 冻结策略配置SHA-256。
- 回测引擎、订单约束、成本模型、信号代码和交易规则的组合SHA-256。
- 已处理历史数据的指纹。

以下情况会停止模拟盘：

- 冻结配置发生改变。
- 算法实现发生改变。
- 已处理过的历史行情被回填或修改。
- 当日ETF行情没有更新到目标日期。

## 数据与成交顺序

```text
本地行情更新
    ↓
验证历史数据和交易日
    ↓
用截至信号日收盘的数据生成目标
    ↓
下一交易日开盘模拟成交
    ↓
处理T+1、涨跌停、费用和公司行动
    ↓
收盘估值并检查现金、持仓、权益对账
    ↓
写入日报和数据库
```

## 历史回放结果

为验证工程闭环，使用冻结多资产策略从2023-10-30回放到2026-10-29：

- 727个日快照。
- 107笔模拟订单，全部成交。
- 107个确定性订单ID，无重复。
- 期末现金84,449.08元。
- 期末持仓市值470,104.40元。
- 期末权益554,553.48元。
- 持仓3只。
- 全部日快照对账通过。

重复执行同一日期后，订单数仍为107，运行记录仍为1，说明重复运行不会重复下单。

该历史回放只验证系统流程，不重新用于策略选择或参数调整。

## 每日操作

首次初始化：

```powershell
uv run quant-paper init --start-date 2026-10-30
```

更新行情后推进到最近已完成交易日：

```powershell
uv run quant-multiasset build
uv run quant-paper run-latest
```

指定日期运行：

```powershell
uv run quant-paper run --as-of 2026-10-30
```

查看状态：

```powershell
uv run quant-paper status
```

每日报告位于：

```text
runs/paper/latest_report.md
```

## 日报内容

- 模拟模式及真实交易关闭状态。
- 冻结配置和代码指纹。
- 现金、持仓市值、总权益和持仓数量。
- 当日订单、拒单原因和交易成本。
- 账户对账结果。
- 临时持仓超限等风险告警。

## 验收标准

- 同一日期重复运行不产生重复订单。
- 已处理历史数据被修改时停止运行。
- 所有成交日期晚于信号日期。
- 每日现金加市值等于权益。
- 行情未覆盖目标日期时拒绝运行。
- 日报能够说明持仓、订单和异常。

## 当前限制

- 当前是收盘后计算并回放当日开盘成交，不是盘前实时下单。
- 没有券商行情和委托回报。
- 没有自动定时任务。
- 没有部分成交、撤单和盘中断线恢复。
