# 第十八步：全研究池每日增量更新

版本日期：2026年10月29日

## 每日流程

每个A股交易日后执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_daily_paper.ps1
```

顺序为：

```text
20只ETF增量行情
→ 公司行动更新
→ 日期、复权、缺日和价格校验
→ 原子替换多资产研究数据
→ 运行模拟盘
→ 账户对账和日报
```

任一数据更新或校验失败时，脚本以非零状态停止，不会继续用旧数据生成新订单。

## 增量策略

每个品种只抓取最近约10个自然日并覆盖上次最后日期：

- 未复权价格用于成交和持仓估值。
- 前复权价格用于信号和收益计算。
- 重叠日期用于检查供应商是否修改历史收盘价。
- 重叠日期的前复权价格若出现尺度变化，说明可能发生新的分红或份额折算，程序会自动回抓该ETF完整前复权历史。
- 内部日期缺口仍为硬错误，不能通过截断或删除日期绕过。

所有品种更新完成后，只有整体校验通过才替换正式研究表。

## 模拟盘联动

一键脚本先调用全池更新，成功后：

- 未指定日期时，模拟盘推进到最近已完成交易日。
- 指定日期时，数据更新和模拟盘使用同一日期。
- 若行情没有覆盖该日，模拟盘拒绝运行。
- 同一日期重复运行不会产生重复订单。

## 运行时间

应在交易日收盘并等待数据供应商发布最终日线后执行。不要在午间使用未收盘日线生成信号。
