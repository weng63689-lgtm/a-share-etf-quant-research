# 项目备忘

**日期：** 2026年10月29日  
**项目名称：** A股ETF量化研究与模拟交易系统  
**项目状态：** 研究与模拟交易阶段  
**项目仓库：** https://github.com/weng63689-lgtm/a-share-etf-quant-research  
**项目展示页：** https://weng63689-lgtm.github.io/a-share-etf-quant-research/

## 一、项目摘要

本项目面向个人账户，独立建立了一套仅投资境内ETF的日频量化研究系统。项目不只包含策略回测，还覆盖数据校验、公司行动、账户核算、A股交易制度、交易成本、风险预算、样本外验证、失败归因和离线模拟盘。

目前已完成从行情数据到模拟交易的完整工程闭环，但冻结策略没有通过最终样本外的正超额收益验收，因此项目严格停留在研究和模拟阶段，没有连接券商，也没有投入真实资金。

## 二、投资范围

- 仅研究境内上市ETF。
- 研究池共20只，覆盖股票、债券、黄金和货币ETF。
- 只做多，不使用杠杆。
- 排除跨境ETF、QDII、杠杆、反向、场外基金、商品期货和直接衍生品。
- 采用日频数据，在收盘后计算信号，下一交易日开盘模拟成交。

## 三、已完成的主要工作

| 模块 | 主要成果 |
|---|---|
| 数据治理 | 保留原始与清洗数据，检查交易日缺口、价格异常、复权口径和公司行动 |
| 账户模型 | 实现现金、持仓、分红、份额折算和事件流水核算 |
| 交易制度 | 接入T+1、整手、停牌、涨跌停和公司行动日参考价 |
| 成本模型 | 纳入佣金、最低收费、ETF税费、滑点、市场冲击和成交容量 |
| 策略研究 | 完成趋势、动量、多周期、低波动和风险预算等候选研究 |
| 验证体系 | 完成样本外、三年滚动窗口、参数邻域和1至3倍成本压力测试 |
| 失败归因 | 分析市场环境、选品边际、换手成本和回撤过程 |
| 模拟盘 | 建立冻结配置、代码指纹、数据版本保护、幂等订单和每日日报 |
| 工程交付 | 提供命令行和本地图形界面，支持一键更新行情并运行模拟盘 |
| 自动化 | 78项自动测试、Ruff检查与GitHub Actions持续集成 |

## 四、关键研究结果

多资产10%目标波动率方案在内部验证期取得：

- 累计收益：30.97%
- 最大回撤：-5.52%
- 相对沪深300超额收益：11.01个百分点
- 3倍成本压力测试后仍保持正收益和正超额

但内部验证期参与了规则设计，不能作为最终证据。规则冻结后的样本外区间为2023年10月30日至2026年10月29日，结果为：

| 指标 | 冻结策略 | 同期沪深300 |
|---|---:|---:|
| 累计收益 | 10.91% | 12.78% |
| 最大回撤 | -8.02% | — |
| 相对收益 | -1.87个百分点 | — |

冻结策略在最终区间保持正收益和较低回撤，但跑输沪深300，没有通过进入真实资金交易的收益条件。五个三年滚动窗口中，三个明显跑赢、一个接近打平、最近一个跑输，说明收益优势并不稳定。

## 六、项目价值

本项目的核心价值不只在策略收益，而在于建立了一套可检查、可复现、可审计的量化研究流程：

1. 将数据错误、复权变化和公司行动纳入强制校验。
2. 把A股交易限制和真实成本放在策略之外单独建模。
3. 使用样本外和成本压力测试约束事后择优。
4. 即使结果不理想，也完整保留并披露失败证据。
5. 用冻结配置、代码指纹和幂等订单保护模拟交易的一致性。
6. 通过自动测试和持续集成保证工程可以重复运行。

## 七、当前限制

- 策略最终样本外未跑赢沪深300，不能宣传为已验证的盈利策略。
- 行情依赖免费数据接口，不能作为实盘唯一数据源。
- 当前为收盘后计算，不是盘前实时决策或盘中止损系统。
- 未连接券商，不具备真实委托、成交回报和撤单能力。
- 交易成本为研究假设，进入实盘前需要按实际券商费率复核。
- 尚未积累足够的真实前向模拟记录。

## 八、下一步计划

1. 连续运行20至30个新交易日，验证每日数据更新、账户对账、告警和日报稳定性。
2. 运行满约60个交易日后，开始初步观察新样本中的因子表现。
3. 运行满约120个交易日后，开展正式的短期和中期因子研究。
4. 运行满约250个交易日后，进行更可靠的长周期因子验证。
5. 在任何新策略达到样本外正超额、风险约束和稳定复现条件之前，不接入真实资金。

## 九、最终结论

本项目已经完成一套较完整的A股ETF量化研究和模拟交易基础设施，适合作为工程能力、数据分析能力和风险意识的展示项目。

但工程完成不等于策略有效。现有冻结策略的风险控制表现稳定，最终样本外收益却没有胜过沪深300。因此当前结论是：**保留为模拟研究候选，不进入真实资金交易。**
