# 第九步：样本外、滚动窗口与参数邻域

版本日期：2026年10月29日

## 检验设计

本节不继续寻找历史收益最高的参数，而是检验第一版规则是否具有稳定性。

时间切分：

- 开发期：至2023-10-29。
- 最终样本外：2023-10-30至2026-10-29。
- 参数网格只在开发期比较，样本外不参与参数选择。

参数邻域包含：

- 动量周期：90、120、160个交易日。
- 趋势周期：120、200、250个交易日。
- 最小组合换手：5%、10%。
- 共18组参数组合。

所有参数组合均使用1倍成本、相同ETF池和相同交易约束。

## 回撤控制

风险覆盖层只在独立场景启用：

| 组合回撤 | 目标风险暴露 |
|---|---:|
| 达到-8% | 70% |
| 达到-12% | 40% |
| 达到-16% | 0% |

完全退出后冷静20个交易日，再以40%风险暴露恢复；组合回撤恢复到4%以内后恢复100%风险暴露。所有比例和冷静期保存在 `configs/default.yaml`。

该机制仍然每周检查一次，不能在盘中阻止跳空或流动性不足造成的损失。

## 样本外结果

样本外从2023-10-30开始计入现金和沪深300基准，即使策略初期没有持仓也不会缩短评估区间。

| 场景 | 累计收益 | 年化收益 | 最大回撤 | 同期沪深300 | 超额收益 |
|---|---:|---:|---:|---:|---:|
| 原始规则 | -1.86% | -0.62% | -28.63% | 12.78% | -14.64% |
| 回撤控制 | -7.41% | -2.53% | -22.22% | 12.78% | -20.19% |

原始规则在样本外由正超额转为明显落后。回撤控制降低了一部分回撤，但仍未低于20%，并因反复减仓、恢复而产生额外损失。

## 开发期与滚动窗口

开发期原始规则年化收益6.65%，最大回撤-45.39%。回撤控制将最大回撤降至-32.08%，年化收益提高到7.13%，但仍远高于20%目标。

| 三年滚动窗口 | 累计收益 | 最大回撤 | 相对沪深300 |
|---|---:|---:|---:|
| 2016-2018 | -9.15% | -17.64% | +4.07% |
| 2018-2020 | 37.90% | -20.42% | +10.40% |
| 2020-2022 | 40.79% | -15.75% | +47.54% |
| 2022-2024 | -23.42% | -24.54% | -3.44% |
| 2023-2026 | -1.86% | -28.63% | -14.64% |

表现明显集中在部分窗口，不能认定收益具有跨周期稳定性。

## 参数邻域结果

18组参数全部在开发期取得正超额收益，但：

- 年化收益中位数6.26%。
- 最大回撤中位数-45.78%。
- 最好最大回撤仍为-38.87%。
- 满足20%最大回撤目标的组合占比为0%。

因此参数邻近组合的收益方向相对一致，但风险失败不是单个参数选择造成的。继续在历史数据上微调参数无法解决风险目标。

## 最终判断

第一版趋势动量规则未通过稳健性验收：

- 最近样本外收益为负，且落后沪深300。
- 参数邻域没有任何组合满足20%回撤目标。
- 收益依赖少数历史窗口。
- 样本外换手仍然过高。
- 回撤控制虽改变结果，但没有形成稳定超额收益。

当前策略禁止进入模拟交易。不能使用已经查看过的近期样本外结果继续反向调参，否则会产生新的选择偏差。

## 运行命令

```powershell
uv run quant-robustness run
uv run quant-robustness summary
```

主要输出：

- `runs/robustness_v1/report.md`：可阅读稳健性报告。
- `data/processed/robustness_scenarios.parquet`：开发期、样本外及风险控制场景。
- `data/processed/robustness_parameter_grid.parquet`：18组参数邻域。
- `data/processed/robustness_rolling_windows.parquet`：三年滚动窗口。
- `data/processed/robustness_summary.json`：机器可读汇总。
