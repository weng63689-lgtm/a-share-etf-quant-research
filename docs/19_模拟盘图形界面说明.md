# 第十九步：模拟盘图形界面

版本日期：2026年10月29日

## 启动方式

双击项目根目录中的：

```text
F:\量化\A股ETF量化\启动模拟盘.bat
```

程序会打开一个本地窗口，不需要在终端输入命令。

也可以在PowerShell中运行：

```powershell
uv run quant-paper-gui
```

## 界面功能

### 一键每日运行

每个A股交易日后点击此按钮：

1. 增量更新全部20只境内ETF。
2. 校验行情、复权和公司行动。
3. 推进冻结版模拟盘。
4. 更新账户和日报。

数据校验失败时不会继续推进模拟盘。

### 只更新数据

只执行全部20只ETF的数据更新，不生成模拟订单。

### 只运行模拟盘

在确认数据已经更新后，只推进模拟账户。

### 刷新状态

重新读取：

- 已处理日期
- 下一交易日
- 总权益
- 现金
- 持仓数量
- 对账和告警状态

### 打开日报和项目文件夹

直接打开最新的模拟盘日报或项目目录。

## 使用顺序

每个交易日：

1. 等待A股收盘和行情供应商发布最终日线。
2. 双击`启动模拟盘.bat`。
3. 点击“一键每日运行”。
4. 等待成功提示。
5. 点击“打开日报”检查持仓、订单和告警。

如果提示数据未更新，不要强行运行。稍后再次更新，或者先检查网络和数据接口。

## 安全边界

- 程序只连接本地数据表。
- 不连接券商。
- 不读取账户密码。
- 不发送真实订单。
- 真实交易开关固定关闭。

## 文件位置

- 图形界面：`src/a_share_quant/paper/gui.py`
- 启动脚本：`启动模拟盘.bat`
- 当前状态：`data/paper/state.json`
- 模拟订单：`data/paper/orders.parquet`
- 模拟净值：`data/paper/snapshots.parquet`
- 最新日报：`runs/paper/latest_report.md`

## 限制

这是本地Python图形程序，不是手机应用或交易所客户端。当前电脑必须能访问项目目录和行情网络。没有配置Windows定时任务，需在每个交易日收盘后双击运行。
