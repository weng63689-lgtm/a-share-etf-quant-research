# 第十一步：第二版结构性候选验证

版本日期：2026年10月29日

## 时间隔离

本步严格使用开发期内部切分：

- 训练期：至2018-12-31。
- 内部验证期：2019-01-01至2023-10-29。
- 2023-10-30以后的最终样本外不参与第二版设计或选择。

## 第二版规则

针对第一版“排名无增量、换手过高、上涨捕获不足”的问题，预先定义以下结构性候选：

- 从周频改为月度调仓。
- 使用60、120、240日动量平均值。
- 使用60、120、200日均线趋势共识，至少满足三分之二。
- 当沪深300低于200日均线时，总目标仓位从90%降至40%。
- 单只ETF上限从45%降至40%。
- 最小组合换手阈值提高到10%。

同时运行消融场景，区分每项改动的效果。

## 内部验证结果

| 方案 | 验证收益 | 年化收益 | 最大回撤 | 相对沪深300 | 年化换手 |
|---|---:|---:|---:|---:|---:|
| 原始周频 | 44.72% | 7.98% | -21.51% | +24.75% | 4.42倍 |
| 仅月度调仓 | 34.24% | 6.30% | -23.43% | +14.27% | 2.06倍 |
| 月度+多周期 | 8.55% | 1.72% | -31.38% | -11.42% | 2.45倍 |
| 完整v2结构 | 10.97% | 2.18% | -24.62% | -9.00% | 2.15倍 |
| v2+回撤控制 | 15.08% | 2.96% | -16.98% | -4.89% | 1.60倍 |

## 结论

月度调仓成功降低了换手，但多周期动量共识削弱了原有信号，沪深300风险过滤也没有在内部验证期产生稳定优势。

预先设定的晋级条件为：

- 内部验证期正收益。
- 内部验证期正超额。
- 最大回撤不低于-20%。

完整v2和回撤控制版本均未通过：

- v2收益为正，但跑输沪深300。
- v2回撤-24.61%，超过风险目标。
- 回撤控制把回撤降到-16.69%，但收益进一步下降，仍跑输基准。
- 最大回撤虽被控制，策略没有产生可接受的风险调整后超额收益。

因此第二版不进入模拟交易，也不使用最终样本外做补救性选择。

## 为什么不能直接保留“仅月度调仓”

“仅月度调仓”在内部验证中取得正超额并大幅降低换手，但最大回撤仍为-23.55%，不满足20%风险目标。它值得作为下一轮研究组件，但不能因为相对其他消融结果更好就直接晋级。

## 运行命令

```powershell
uv run quant-candidate run
uv run quant-candidate summary
```

主要输出：

- `runs/structural_v2/report.md`：可阅读消融报告。
- `data/processed/structural_scenarios.parquet`：训练和验证场景绩效。
- `data/processed/structural_snapshots.parquet`：逐日账户结果。
- `data/processed/structural_orders.parquet`：订单和交易成本。
- `data/processed/structural_v2_summary.json`：机器可读结论。
