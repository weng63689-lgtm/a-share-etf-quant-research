# 工作备忘：A股ETF量化系统每日数据更新

**日期：** 2026年10月29日  
**适用对象：** 项目使用者及后续交接人员  
**项目范围：** 仅限境内ETF

## 一、结论

本系统采用“联网增量下载、本地存储、本地计算”的运行方式。每日不需要手动上传行情文件，也不需要把数据同步到GitHub；只需在A股交易日收盘后启动模拟盘，点击“一键每日运行”。

系统会自动更新境内ETF行情、校验数据、推进模拟账户并生成日报。行情、模拟账户和运行结果均保存在本机，不进入公开仓库。

## 二、每日操作

1. 在A股交易日收盘、且行情供应商发布最终日线后，打开 `F:\量化\A股ETF量化`。
2. 双击 `启动模拟盘.bat`。
3. 点击“一键每日运行”。
4. 等待界面显示更新成功。
5. 点击“打开日报”，检查订单、持仓、账户变动和告警。

如果只需要补充行情、不推进模拟盘，可以点击“只更新数据”。

## 三、系统自动执行的内容

- 增量下载20只研究用境内ETF的最近行情。
- 更新分红、拆分等公司行动。
- 检查交易日、复权价格、缺日和异常价格。
- 原子替换本地正式研究数据，避免半完成数据进入策略。
- 运行冻结版 `multi_asset_v1` 模拟策略。
- 更新模拟账户、订单、净值和每日报告。

任一步骤失败时，后续模拟盘不会继续使用未通过校验的数据。

## 四、本地文件与公开仓库

主要本地数据位置：

- `data/raw/`：供应商原始增量数据
- `data/processed/`：清洗和校验后的研究数据
- `data/paper/`：模拟账户、订单和净值
- `runs/paper/latest_report.md`：最新模拟盘日报

公开GitHub仓库仅用于保存代码、说明文档和研究结果，不保存每日行情、账户状态或交易数据。因此无需每天向GitHub上传文件。

## 五、注意事项

- 不要在交易日午间使用未收盘行情生成信号。
- 如果提示行情尚未更新，不应强行推进；稍后重新执行。
- 更新过程需要能够访问行情数据接口。
- 当前系统不连接券商、不读取账户密码、不发送真实订单。
- 当前结果用于研究和模拟验证，不构成真实交易的收益保证。
